# C8.4 - Raw Modality Confidence and Holdout Isolation

## Motivation

C8.3 produced no feasible abstention policy: calibration-only rank/score/lexical rules could reduce false positives only by sacrificing too much recall. Its holdout is consumed and must not be reused.

The recall API currently exposes source ranks but discards the HNSW distance and FTS5 `rank` value. C8.4 adds those values as optional telemetry while leaving candidate order, RRF, boosts, and final ranking unchanged.

## Raw fields

- `VectorDistance`: HNSW's current Euclidean distance; lower is closer. This is not cosine similarity.
- `FTS5RankScore`: the SQLite FTS5 `rank` value returned by the keyword leg. The raw value is preserved; observed ordering is the existing `ORDER BY rank` order.
- A missing source value is absent/null, distinct from a numeric zero. Source ranks remain the presence indicators.
- Calibration can also compute top-two source-distance/rank-score margins from the returned candidates; those are diagnostic features, not RRF inputs.

## Holdout protocol correction

Do not query or compute any holdout metrics until calibration has selected a policy that passes the calibration gates. If no feasible policy exists, return `holdout_evaluated=false`, omit holdout metrics, and stop. If a policy is selected, evaluate it once on the fresh holdout; if it fails, that holdout is consumed and cannot be tuned against.

## C8.4 corpus and gates

- New synthetic-only corpus: 90 records, 120 queries, balanced 60/60 calibration and holdout splits, disjoint from C8.1/C8.3 identifiers, markers, and query text.
- Calibration features include the existing scalar/rank evidence plus raw source distances/scores and joint raw-source cutoffs.
- Gate thresholds remain Recall@5 >= 0.90, exact-ID recall = 1.00, no-answer FPR <= 0.05, and zero namespace/forbidden-marker leakage.
- The C8.3 holdout must never be reused.

The runtime image and manual C8.4 workflow are gated on merging the raw-score source change and publishing a new immutable image. No production DB/HNSW, provider/Hermes, context injection, VM/WS-1, collector, Residual Pack, C9, or deployment is in scope.
