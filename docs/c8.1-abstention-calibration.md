# C8.1 - Synthetic Abstention Calibration

## Purpose

C8 showed 100% false positives on five no-hit queries. C8.1 checks whether a retrieval-only abstention rule can separate answerable from unanswerable synthetic queries without using the holdout set for tuning. It does not change Nyawa's search implementation or inject candidates into Hermes.

## Corpus and split

`scripts/c81_fixture_generator.py` creates the deterministic JSON fixture at runner time:

- 90 synthetic records; 120 unique queries.
- 60 answerable and 60 unanswerable queries.
- 60 calibration cases and 60 holdout cases; each split has 30 answerable and 30 no-answer cases.
- Answerable categories: exact identifier (10 per split), semantic paraphrase (5), bilingual paraphrase (5), namespace isolation (5), and active-vs-retired filtering (5).
- No-answer categories: 6 each per split for hard semantic, hard lexical, near identifier, scope confusion, and out-of-domain.
- Calibration/holdout query text and positive target markers are disjoint. No secret-shaped contiguous strings or real memories are allowed.

## Signals and procedure

Each query requests the top five candidates with `min_score=0`, so the underlying ranked list is recorded before abstention. The report stores only fixture IDs, ranks, final `Score`, raw `RRFScore`, returned temporal/importance boosts, `VectorRank`, `FTS5Rank`, lexical coverage, exact-ID match, and rank margins; it never stores candidate text. A source rank is one-based when present and `0` when that retrieval leg did not return the candidate.

The evaluator compares shadow-only rules based on score, margin, lexical evidence, and modality ranks/agreement. It selects a rule and threshold using **calibration cases only**, requiring the approved gates and complete numeric modality evidence. That fixed choice is then evaluated once against holdout. If no calibration policy meets all gates, the run fails closed and no holdout-selected threshold is reported.

## Approved gates

- Positive Recall@5 >= 0.90.
- Exact-identifier recall = 1.00.
- No-answer false-positive rate <= 0.05.
- Namespace and forbidden-marker leakage = 0.

A C8.1 `PASS` requires a feasible calibration policy and that same frozen policy to pass every gate on holdout. Calibration-only sweep points are diagnostic; they do not replace holdout results.
