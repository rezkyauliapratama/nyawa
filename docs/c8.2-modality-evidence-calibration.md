# C8.2 - Modality Evidence for Abstention Calibration

## Why this extension exists

C8.1 tested final `Score`, `RRFScore`, score margins, and synthetic lexical overlap. None met the approved holdout gates. The C8.1 run returned no feasible policy; do not proceed to C9/WS-1 based on that result.

This additive API field exposes which retrieval legs returned a candidate so a later synthetic-only calibration can test modality provenance and agreement. It does not change ranking, candidate ordering, score calculation, or `min_score` behavior.

## API fields

Each REST `/v1/recall` result includes:

- `VectorRank`: one-based rank from HNSW/vector retrieval; `0` means absent from that leg.
- `FTS5Rank`: one-based rank from FTS5 retrieval; `0` means absent from that leg.

A result found by both legs has two positive ranks. A graph-only result has both ranks `0`. These are provenance signals, **not confidence or probability scores**. They must be tested on a calibration split and a frozen holdout before being used for abstention.

## C8.2 run disposition

The synthetic run [#42543678323](https://github.com/rezkyauliapratama/nyawa/actions/runs/42543678323) completed all 90 inserts, indexed all 90 vectors, and queried all 120 cases with numeric modality fields. Cleanup passed. It returned `FAIL` with no selected abstention policy; the no-answer raw-retrieval FPR was 1.00.

A source audit found that `VectorSearchAt` receives HNSW results in distance order, but `filterActiveIDs` rebuilt its result by iterating an SQL `WHERE id IN (...)` result with no `ORDER BY`. SQLite does not guarantee that order, so namespace/time-scoped `VectorRank` values could differ from HNSW order, affecting RRF and final ranking too. Therefore this run is evidence of the implementation as built, but **not valid evidence for intended vector-rank calibration**. Treat its holdout as consumed; do not tune or validate another policy against it.

C8.3 must first restore HNSW ordering after filtering, then use a new synthetic corpus with a fresh, disjoint holdout and a newly built immutable image. C9/WS-1 remain blocked.

No production, provider, Hermes, VM/WS-1, context injection, collector, or Residual Pack is in scope.
